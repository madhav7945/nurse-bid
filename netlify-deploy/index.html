Why doesn't iPhone allow direct "Download & Install" like Android?

Unlike Android which allows users to download and install raw APK files directly from web browsers, Apple strictly locks all iOS devices under a cryptographic sandbox. iPhones physically block installing raw app files from websites unless routed through Apple's official tools.
